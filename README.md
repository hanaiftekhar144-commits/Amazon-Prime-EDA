# Amazon Prime Video Data Analysis (EDA Project)

## 📊 Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Amazon Prime Video dataset to uncover insights related to content trends, ratings, and platform distribution.

The dataset contains information about movies and TV shows including genres, release years, ratings, cast, and production countries. 

The analysis helps understand how content is distributed across the platform and what factors influence ratings and popularity.

---

## 🎯 Business Objective
The main goal of this project is to:

- Understand content distribution on Amazon Prime Video  
- Identify popular genres and high-performing content  
- Analyze trends in content release over time  
- Study factors affecting ratings and popularity  
- Provide data-driven insights for content strategy  

---

## 🔍 Steps Performed

### 🧹 Data Preprocessing
- Imported and explored datasets (titles.csv & credits.csv)  
- Handled missing values and inconsistencies  
- Removed duplicates  
- Encoded categorical variables (type, genre, country)  
- Performed feature engineering:
  - Extracted release year  
  - Split multiple genres and countries  
- Merged datasets for complete analysis
