# Amazon Prime EDA

## 📊 Overview
Exploratory Data Analysis of Amazon Prime Video dataset to uncover content trends and insights.

## 🧹 Data Preprocessing
- Handling missing values
- Data cleaning
- Feature engineering
- Merging datasets

## 📈 EDA Insights
- Movies vs TV Shows distribution
- Genre analysis
- Ratings distribution
- Release trends
- Top countries, actors, directors
